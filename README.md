# Личный ассистент в Telegram

Бот умеет:
1. **Напоминания** — «напомни завтра в 12:00 обработать заказ»
2. **Запись заказов в Google Таблицу** — просто опиши заказ свободным текстом.
   Бот сам генерирует короткий номер заказа (например `A1042`) и присылает его в ответ —
   передай этот номер клиенту.
3. **Изменение статуса заказа** — «статус A1042 = 3» (число 1-6, см. таблицу ниже)
4. **Трекер заказов для клиентов** — Telegram Mini App, где клиент вводит номер заказа
   и видит текущий этап доставки. Открывается кнопкой «📦 Отследить заказ» в боте (`/track`).
5. **Разбор конкурентов/рекламных каналов** — пришли ссылку на публичный канал (t.me/name)

Всё остальное (обычные вопросы) бот тоже понимает — отвечает как обычный ассистент.

### Этапы заказа (колонка "Статус" в таблице, число 1-6)
1. Товар выкуплен
2. Прибыл на склад в Китае
3. Едет Китай → Москва
4. Прибыл в Москву
5. Передан в доставку
6. Доставлен

---

## Шаг 1. Получить токен Telegram-бота

1. Напиши в Telegram боту **@BotFather**
2. Команда `/newbot`, придумай имя и username (должен заканчиваться на `bot`)
3. Получишь токен вида `123456789:AAExxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx`
4. Сохрани его — это `TELEGRAM_BOT_TOKEN`

## Шаг 2. Получить ключ Gemini API

1. Зайди на **aistudio.google.com/apikey**, войди с Google-аккаунтом
2. **Create API key**
3. Сохрани ключ — это `GEMINI_API_KEY`

## Шаг 3. Настроить доступ к Google Таблице

1. Зайди на **console.cloud.google.com**, создай новый проект (или используй существующий)
2. Включи **Google Sheets API** и **Google Drive API** (Библиотека API → найти → Включить)
3. Раздел **IAM и администрирование → Сервисные аккаунты → Создать сервисный аккаунт**
4. После создания — открой аккаунт → вкладка **Ключи** → **Добавить ключ → JSON**
5. Скачается файл — переименуй его в `credentials.json` и положи в корень проекта
6. Открой файл, скопируй значение `"client_email"` (выглядит как `xxx@xxx.iam.gserviceaccount.com`)
7. Открой свою Google Таблицу с листом **«Заказы»** → кнопка **«Настройки доступа»** →
   добавь этот email как **Редактора**
8. Скопируй **ID таблицы** — это часть ссылки между `/d/` и `/edit`:
   `https://docs.google.com/spreadsheets/d/ВОТ_ЭТО_ID/edit`

Колонки **«Номер заказа»** и **«Статус»** добавлять руками не нужно — бот сам допишет
заголовки в конец листа при первом обращении к таблице, если их там ещё нет.

## Шаг 4. Настроить переменные окружения

Скопируй `.env.example` в `.env` и заполни все значения:

```bash
cp .env.example .env
```

`OWNER_CHAT_ID` пока можно оставить пустым — узнаешь его после первого запуска (бот покажет в ответ на `/start`).

## Шаг 5. Запустить локально (для проверки)

```bash
python -m venv venv
source venv/bin/activate  # на Windows: venv\Scripts\activate
pip install -r requirements.txt
python -m bot.main
```

Напиши боту `/start` в Telegram — если ответил, всё настроено верно.

Проверить подключение к таблице отдельно:
```bash
python -m bot.sheets_service
```
Если в таблице появилась тестовая строка — доступ настроен правильно.

Проверить трекер заказов локально (без бота, только API + Mini App статика):
```bash
uvicorn bot.api:app --reload --port 8080
```
Открой `http://127.0.0.1:8080/app/` в браузере — увидишь ту же страницу, что откроется
в Telegram (вне Telegram `Telegram.WebApp.CloudStorage` недоступен, список заказов
сохраняется в `localStorage` браузера как запасной вариант).

## Шаг 6. Задеплоить на Railway (чтобы бот работал 24/7)

1. Залей код в свой репозиторий на GitHub
2. Зайди на **railway.app**, войди через GitHub
3. **New Project → Deploy from GitHub repo** → выбери свой репозиторий
4. Во вкладке **Variables** добавь все переменные из своего `.env` (кроме `GOOGLE_CREDENTIALS_FILE` —
   вместо пути, для credentials.json есть два варианта см. ниже)
5. Railway сам определит `Procfile` и запустит бота (процесс `web`, слушает `$PORT`)
6. Открой вкладку **Settings → Networking → Generate Domain** — Railway выдаст публичный
   https-адрес вида `https://your-app.up.railway.app`, он проксируется на `$PORT`, который
   слушает встроенный API/Mini App сервер
7. Впиши в Variables `MINI_APP_URL=https://your-app.up.railway.app/app/` (со слэшем в конце)
   и передеплой — после этого в боте появится кнопка «📦 Отследить заказ»

Регистрировать Mini App через @BotFather не нужно — кнопка `web_app` в обычной клавиатуре
работает с любой https-ссылкой без дополнительной настройки.

### Как передать credentials.json на Railway
Так как это чувствительный файл, а не текстовая переменная, есть два пути:
- **Проще:** добавить `credentials.json` в репозиторий (если репозиторий приватный) — тогда ничего менять не нужно
- **Безопаснее:** создать переменную `GOOGLE_CREDENTIALS_JSON` с полным содержимым файла в виде текста —
  `bot/config.py` уже умеет сохранять её в `credentials.json` при старте, если сам файл не задеплоен

## Структура проекта

```
tg-assistant/
├── bot/
│   ├── main.py              # точка входа: бот + запуск API в отдельном потоке
│   ├── config.py            # загрузка переменных окружения
│   ├── api.py                # FastAPI: GET /api/status/{order_number} + статика Mini App
│   ├── gemini_service.py    # общение с Gemini (распознавание намерений)
│   ├── sheets_service.py    # запись в Google Таблицу, номера/статусы заказов
│   ├── scheduler.py         # планировщик напоминаний
│   └── channel_analyzer.py  # загрузка постов публичных каналов
├── webapp/                  # Telegram Mini App (трекер заказов для клиентов)
│   ├── index.html
│   ├── style.css
│   └── app.js
├── requirements.txt
├── Procfile                 # команда запуска для Railway (web, слушает $PORT)
├── .env.example
└── README.md
```
